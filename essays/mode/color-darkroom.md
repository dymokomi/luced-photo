# Color Darkroom

The color negative printed by hand on RA-4 paper, as minilabs and professional labs did from the 1980s on. The printer dials in yellow, magenta and cyan filtration in CC units to remove the negative's orange mask and any color cast, and sets the exposure by time.

This mode starts from Kodak Portra 400 printed on Kodak Endura Premier. Raise the yellow to make the print bluer, the magenta to make it greener: each filter holds back its own color's light from the paper.
