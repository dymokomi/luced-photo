# Ilford ID-11

Ilford's ID-11 is essentially the same formula as Kodak's D-76: metol and hydroquinone with about 100 grams per litre of sodium sulfite. Ilford describes it as giving full emulsion speed with fine grain, and it has been the reference developer in Ilford's own data sheets for decades.

Ilford's rule for temperature is simple and generous: ten percent more time for each degree below 20 °C, ten percent less for each degree above. Acros II's data sheet gives it 6¾ minutes at 20 °C.
